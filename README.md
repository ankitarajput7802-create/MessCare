# MessCare

Hostel Mess Complaint & Feedback System
## Description

MessCare is a web-based system designed to help hostel students
raise and manage mess-related complaints in an organized way.
## Features

- Raise hostel mess complaints
- Select complaint type
- Store complaints in a database
- View submitted complaints
- Track complaint status
## Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** SQLite
- **Version Control:** Git & GitHub
